Zero-Write Architecture

How PriVis Syncs with Active Directory

PriVis deploys a lightweight, read-only Windows collector service inside your network perimeter. It never requires Domain Admin privileges and never modifies your directory automatically.

STEP 01 // COLLECT

Read-Only LDAP & SYSVOL Sync

Using a standard unprivileged service account, the PriVis Collector queries LDAP over TLS (port 636) and inspects SYSVOL GPO definitions on a configurable 15-minute cadence.

STEP 02 // EVALUATE

Policy & Privilege Graph Analysis

The PriVis intelligence engine resolves nested group memberships, compares worker end dates against enabled flags, and detects credential exposure in seconds.

STEP 03 // ALERT & REMEDIATE

Admin Alerts & PowerShell Output

High and Critical violations trigger webhook, Slack, Teams, or SIEM alerts alongside exact PowerShell commands so administrators retain full change control.

Install-PriVisCollector.ps1
